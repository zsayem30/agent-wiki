# Roadmap

This is the first version of `agent-wiki`. Likely future work includes:

- an installation command that merges root `opencode.json` instead of requiring
  manual copy/merge;
- stronger host OpenCode config linting;
- richer run-card and claim-registry validation;
- optional GitHub Action for host projects;
- generated HTML atlas over wiki and knowledge registries;
- migration tools for existing large `docs/` folders;
- examples for multiple research project archetypes.

The design should stay curator-first: host agents do the work, `agent-wiki`
preserves clean memory.
