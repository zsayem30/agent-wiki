# Paper Cards

This file can hold compact paper cards when the project is small. For larger
projects, keep detailed paper notes in `sources/papers/` and structured
metadata in `knowledge/paper_registry.yaml`.

## Template

```text
### Paper Title

Status: candidate / foundational / competitor / background / rejected
Citation:
Link:
Relevance:
Key Ideas:
Limitations:
Implementation Hooks:
Related Claims:
```
